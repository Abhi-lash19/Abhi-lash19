**GitInsight Engine** — a modular Node.js analytics service that aggregates GitHub statistics across the REST and GraphQL APIs. It computes stars, forks, languages, contributions, traffic and code-frequency data into structured JSON for dashboards, README badges and deployable stat services, with built-in rate-limit handling and retries.

Contributions, ideas and issues are welcome.
